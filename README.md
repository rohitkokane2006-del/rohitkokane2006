# Rohit Kokane — GitHub Pages Portfolio

A responsive dark-modern portfolio website for internship and placement applications.

## Files
- `index.html` — complete website (HTML, CSS and JavaScript)
- `assets/profile-photo.svg` — temporary profile-photo placeholder

## 1. Add your real profile photo
1. Choose a professional, square photo.
2. Upload it into the `assets` folder in your GitHub repository.
3. Name it `rohit.jpg`.
4. In `index.html`, find:
   `src="assets/profile-photo.svg"`
5. Change it to:
   `src="assets/rohit.jpg"`

## 2. Personalize your links
In `index.html`, search for and replace:
- `YOUR_EMAIL@example.com`
- `YOUR_LINKEDIN`
- `YOUR_GITHUB_USERNAME`

Also add your expected graduation year and update the skills to match what you can confidently demonstrate.

## 3. Publish with GitHub Pages
1. Create a public repository named exactly `YOUR_GITHUB_USERNAME.github.io`.
2. Upload `index.html` and the entire `assets` folder to the repository root.
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then click **Save**.
6. Visit `https://YOUR_GITHUB_USERNAME.github.io` after the deployment completes.

## 4. Add project evidence
For each project, upload your own circuit photographs, diagrams or demo video links. Add only genuine work and accurate descriptions. You can also add a PDF resume named `resume.pdf` and link it from the hero section if you want a resume-download button.
